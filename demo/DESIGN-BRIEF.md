# 把「上下文批改台」原型交给外部设计师（V0 / Jimmy 等）

> 这份文件的用途：**可以直接转发给设计师**。它说明"给哪个文件、哪些能动、哪些绝对不能动、交付什么"。
> 生成时间：2026-10-01 · 单文件版指纹 `079c275`（改了 css/js 后这个指纹会变，见下）

---

## 1. 给他哪个文件

**只给一个文件就够了**：

```
demo/redline-panel.standalone.html
```

- 它是**自包含单文件**：167 KB / 2324 行，恰好 1 个 `<style>` + 1 个 `<script>`，**没有任何外部 css/js/图片/字体**，
  也不需要服务器 —— 双击用浏览器打开即可（离线可用）。
- 页头会显示 `交互原型 v1 · 单文件版 <指纹>`，指纹 = `sha256(demo.css + demo.js)` 前 7 位。
  **用它核对"他手上是哪一版 / 他改的是哪一版"**。
- 想同时给"多人协作版"（多文件、带自测面板）也可以给整个 `demo/` 目录，但那要起一个小服务，
  对设计师不友好。**默认只给单文件版。**

## 2. ⚠️ 一个必须说清的事：这个文件是**生成物**

- 它的来源是 `demo/demo.css` + `demo/demo.js` + `demo/redline-panel.html`，
  由 `node demo/build-standalone.mjs` 打包合并而来。
- 所以设计师**可以随便改这个文件**（当设计稿改），但**不能把它当成新的源文件** ——
  下一次重新打包，他的改动会被覆盖。
- **交付方式（按优先级）**：
  1. **最好**：只改文件里 `<style> … </style>` 那一段，把**整段 CSS 交回来**
     —— 我们直接替换 `demo/demo.css`，风险最低、最好合并；
  2. 或者：给一张**静态视觉稿**（Figma / 截图）+ 文字说明（哪里改成什么），我们照着实现；
  3. 最后：把改过的整份文件交回来也行，我们自己 diff 出差异再搬。
- 无论哪种，**请在交付说明里写清：改了哪些选择器、有没有动 HTML 结构**。

## 3. 哪些**可以**改

- 颜色、间距、字号、圆角、阴影、边框、图标（可用内联 SVG）、动效时长与曲线；
- 页面的整体布局（我们是：`header.topbar` + `main.cols` 里两个 `section.col` 左右两列，
  窄屏自动变单列 —— 这一层可以重新设计）；
- 卡片内部的分块排布（例：「快照与子会话」现在分 4 块 `data-block="freeze|children|pending|team"`，
  宽屏两列、窄屏单列 —— 可以重新设计，但**块的内容顺序与分组含义不要变**）；
- 文案的**措辞**可以提建议（但**含义不能改**，很多文案是规格逐字要求的）。

## 4. 哪些**绝对不能**动（动了会被我们的自动护栏挡下，或者违反平台约束）

### 4.1 结构性钩子：`class` / `id` / `data-*` 一律保留

护栏按这些名字锁定行为与测试。**设计时请把它们当成"接口"，只改它们的样式，不改名字、不删元素**：

| 钩子 | 干什么用 |
|---|---|
| `#cardStats` `#cardTrend` `#cardStep` `#cardEvents` `#cardInfo` `#cardBrowser` `#cardBlocks` `#cardOrch` | 各张卡的容器（JS 往里渲染） |
| `.tbar` `.tbar-fill` `.tbar-stack` `.cseg` `.arm-up` `.arm-down` `.zeroline` | 趋势图柱体（含 hover / 选中 / 叠加段 / 零线） |
| `[data-explain]` + `.exnum` | 讲解模式的编号与高亮（**编号是挂在元素上的小圆标**） |
| `.qfloat` + `.qwrap` | "点开才出现"的按钮左上角那个小问号（**必须在元素左上角外飘**，不能放到按钮后面） |
| `.pickwrap` | `select`/`input` 外面包的那层（编号装不进表单控件，必须包一层） |
| `.targetbox` `.evrow` `.evhint` `.orchblock` `.blocktitle` `.pickone` `.esteps` `.adv` | 目标框 / 事件行 / 块标题 / 选项 / 步骤说明 / 高级折叠 |
| `data-act="…"` `data-block="…"` `data-cat="…"` | 行为与分组标记（**名字不许改**） |

### 4.2 平台/产品硬约束

1. **必须用主题令牌，不要写死颜色**：`--dsw-alias-*`（文字/边框/底色层级）、`--ds-color-*`（语义色：indigo/amber/green/purple/orange/blue/teal）。
   原因：要**同时适配浅色与深色**；深色由 `body[data-ds-dark-theme]` 切换（不是 media query）。
2. **不许用 emoji**（文档明确禁止），状态用圆点/徽章/文字。
3. **不许用 `filter: brightness(...)` 去表达 hover/选中** —— 我们踩过坑：柱体颜色会因此和右侧分类树对不上。
   用底色 tint / 描边 / 透明度代替。
4. **讲解模式的高亮只能画在伪元素上**（`::after`），不许给元素自身加 `outline/background/border`
   （否则会覆盖元素自己的样式，柱体的 hover/选中就看不出来了）。
5. **触控目标 ≥ 44×44 px**；**窄屏（390px）不许出现横向滚动**。
6. **按钮不许"凭空消失"**：某个动作**在当前状态下**不可用时，要留一个标记 + 一句原因（例如灰字徽章），而不是把它删掉。
   **唯一例外（请按例外做，别"补"回来）**：**平台服务整体缺席 / 能力开关为 false** 时，对应入口**必须不存在**
   （不是报错、也不是置灰）—— 例如本机没启用官方智能体团队时，`派活` / `建成官方任务` / 团队成员式`打断` **全都不出现**
   （`docs/03` R2.3 / R5.1 / `docs/06` §3.2）。"某条数据不支持该动作"**不属于**例外，仍要留标记 + 原因
   （例：某条冻结记录比当前最后一个轮次末更早 → 不给 `从这里开子会话`，给一行原因）。
7. **数值一律等宽字体**（token 数、seq、时间），便于对齐扫读。

## 5. 建议的自测（他改完自己就能查）

- 打开文件后**拖窗口**：390px（手机）/ 768px（平板）/ 1440px（桌面）三档看排布；
- 页头右上角有个 **`说明`** 按钮 = 讲解模式；页头还有一排**状态开关**（可以切换"团队可用/轮次未结束"等边界态）；
- 深色：在浏览器控制台执行 `document.body.setAttribute('data-ds-dark-theme','')` 即可看深色版（再执行一次
  `removeAttribute` 回到浅色）；
- 如果拿到的是多文件版，URL 加 `?dev=1` 会开一个**自测面板**，里面直接显示元素尺寸/是否溢出等读数。

## 6. 我们最想要的交付物（一句话）

> **一份只改视觉的 CSS**（改单文件里 `<style>` 那一段，整段交回），
> 并说明"改了哪些选择器 + 有没有动 HTML 结构"；HTML 里的 `class`/`id`/`data-*` 一律保持原样。

这样我们能一次合并、跑一遍护栏、重新打包出带新指纹的单文件版给你确认。
