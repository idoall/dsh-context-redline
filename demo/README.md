# 交互原型（demo）· 怎么用 / 怎么提意见

> **这不是插件代码**，是一个**可点击的规格书**：把 [`docs/03`](../docs/03-ui-spec.md) 的交互逐条做出来给你点。
> 全部数据是假的、全部动作只改本地状态 —— **不发任何请求、不碰你的真实会话**。

## 打开

```bash
# 仓库根目录执行（已在本机起好服务时不用再跑）
bash demo/serve.sh status       # 是否在跑
bash demo/serve.sh              # 起服务（**后台常驻**，跟这个终端退不退出无关）
bash demo/serve.sh stop         # 停
bash demo/serve.sh fg           # 要前台跑、Ctrl-C 停，用这个
```

- 本机：<http://127.0.0.1:5180/redline-panel.html>
- 局域网（手机/其它设备，若防火墙允许）：<http://10.0.0.30:5180/redline-panel.html>
- 单文件独立版（内联 css/js，**连服务都不用**、可 file:// 双击 / AirDrop 到手机）：
  [`redline-panel.standalone.html`](redline-panel.standalone.html) 或
  <http://10.0.0.30:5180/redline-panel.standalone.html>

> **怎么确认你看到的是最新版**：页头那颗标签写着 **`交互原型 v1 · 单文件版 <指纹>`**（7 位）
> —— 那是 `demo.css + demo.js` 的 sha256 前 7 位。改完 css/js 必须跑
> `node demo/build-standalone.mjs` 才会同步；**忘了跑会被 `check-static.mjs` 抓成红的**。
> 把那个指纹告诉我，我就能确认你手上是哪一版。
>
> 服务由 [`serve.py`](serve.py) 提供，统一发 `Cache-Control: no-store`（照旧是只读、不写盘）——
> 刷新就是最新版。之前用 `python3 -m http.server` 时不发这个头，浏览器会把**没有查询串**的
> 单文件版缓存起来，让人以为改动没生效（2026-09-30 实际发生过一次）。
>
> **它是守护进程，不是 shell 后台任务**：以前用 `nohup … &` / 终端后台任务起，父进程一收工服务就没了
> —— 表现就是"刚才还能开，现在打不开了"（2026-09-30 发生过）。现在 `serve.py --daemon` 用双 fork + setsid
> 脱离会话（`ps` 里 PPID=1、无控制终端），pidfile 在**端口绑定成功之后**才写，日志在
> `/tmp/redline-demo-5180.log`。**重启电脑后需要重新 `bash demo/serve.sh` 一次**。

## 顶栏那排状态开关（**最重要的验货工具**）

它们模拟宿主的真实状态，**切换后按钮可见性与文案必须按规范立刻变化**：

| 开关 | 关掉/打开会看到什么 | 依据 |
|---|---|---|
| **轮次未结束** | 写会话类按钮**全部不出现**；本地可逆写入（草稿/固定块）仍可用；顶部出现说明条 | R4.4 / R2.3 |
| **会话在本进程**（关掉） | 整列动作条禁用 + 说明条；版本历史仍可只读 | R4.4 / R4.6 |
| **官方团队可用**（关掉） | `派活` / `建成官方任务` / `去官方面板` **全部消失**（不是置灰、不是报错 —— `docs/03` R5.1 要求"不出现"）；团队区块变成一行"未启用"；`打开` / `压缩` / `打断` 保留（这时的打断走裸子会话通道 `interruptByParent`） | `docs/03` R5.1 / `docs/01` F32 / `docs/06` §3.2 |
| **高级编辑**（打开）| 工具结果那一类才会出现 `编辑`（默认收起 —— 一轮几十条工具结果，把常用动作淹掉）。收起时留 `高级编辑` 小标记，不是凭空消失 | `docs/03` R2.5 / R2.3 |
| **子会话正忙**（打开）| 点`压缩` → 被人话拒绝：*"子会话正在运行，等它空闲再压缩。（busy）"* | `docs/06` §5 |
| **草稿 N 条**（点一下）| 加一条演示草稿 → 行上出现`未生效`、**吸顶条**出现、`应用到会话`按钮才出现 | R4.1 / R5.2 |
| **回流未确认** | 下方"待处理的结果"从"已收到结算通知"切成 **回流未确认**（父 Agent 当时不在进程 → 平台不投递） | R5.1 第 4 项 / `docs/01` F12.1 |

## 请重点验这几处（也是我最怕做错的地方）

1. **一行上到底该有哪些按钮**（**这就是"哪些内容能编辑"的完整答案**）—— 逐个展开这 7 类，逐条看：
   - `系统提示词` / `工具定义` → **没有动作条，也不留空占位**（宿主保护，改不了）；
   - `技能注入` → `编辑` + `批注` + **`钉住这一段`**（＝**只存本地**，开新子会话时逐字带进新会话；同一条原文只钉一次，钉过的行改显示 `已钉住 · vN`）；
   - `工具结果` → `编辑`（编辑器里**只有结果文本 + `isError` 开关**，没有思考文本）+ `批注`。
   以下按 `用户消息` 类逐条看：
   - `#1240` 原始节点 → `编辑` + `批注`；
   - `#1301` **替换体（当前可见）** → **仍有`编辑`**（可连续改）+ `版本历史`；
   - `#1287` **已被遮蔽的原文** → **没有`编辑`**，给一句原因 + `版本历史`；
   - `#1293` **助手消息** → **只给`批注`** + 原因（平台两条规则互斥）；
   - `#1295` **工具结果** → `编辑`（只改内容文本/错误标记）；
   - `#1297` **注入内容** → `编辑` + `批注` + `钉住这一段`；
   - `#1303` **被压缩埋掉** → 只能批注。 → 依据 `docs/03` R2.2 / R4.6
2. **草稿 → 应用 → 版本历史 → 恢复** 整条链（这是图 2 ④ 的核心）：
   在 `#1240` 点`编辑` → 改几个字 → `保存草稿` → 行上出现`未生效` → `应用到会话`（**确认框里有本次清单**）→ 原文变`已被 #1600 接替`、出现新条目 → 点`版本历史` → 选"原始" → `从这一版恢复`（**二次确认**）→ 行上多出回滚关系。
3. **文案是否说人话**：每个确认框的**短警示**（会发生什么/能不能撤回）+ **本次清单**。觉得哪句别扭，直接告诉我改哪句。
   - 编辑器里：主字段只有**「正文」**（思考文本收在「高级」折叠里）；「保存草稿」旁边写着**两步流程**；
     **每个动态出现的按钮旁边都有 `?`** —— 点它弹说明（这是按你的建议加的，讲解模式给不了这类按钮稳定编号）。
   - 特别看 **`批注` 的确认框**：它必须让你看清"这条更正在**快照 / 子会话**里到底起什么作用"（请求式、不遮蔽原文、可能被压缩吞掉，想要确定生效要改用「编辑」+「应用到会话」）。
4. **子会话**（卡内按内容分成**四块**：开子会话 / 子会话索引 / 待处理的结果 / 官方团队；
   宽屏两列并排、窄屏单列但每块有自己的边框与标题 —— 拖窗口跨过 1040px 就能看到排布切换）：`开启子会话`（一个常驻按钮，确认框里你要写首条任务）→ 索引行上的 `发消息 / 派活 / 建成官方任务 / 压缩 / 打断`（各自确认框不同）→ 团队区块只读。
   - `开启子会话` 是**一个常驻按钮**：**不需要先做任何前置动作**（用户 2026-10-02 把"冻结"整套删掉了 —— `docs/11` D10）。
   - **起点由平台定，不由你选**：新会话只会带上"本会话**最后聊完的那一轮**"之前的全部内容，**没有任何参数**能挑更早的位置（`docs/01` F38）。
     确认框第 ① 项就把这句话原样告诉你（`本会话「最后聊完的那一轮」为止 … 平台自己算的，改不了`），所以界面上**不会**出现"从某条记录开"这种承诺。
   - 弹出窗里的字**一律说人话**（用户 2026-10-02：「弹出窗里的描述文字太 AI 化」）：
     确认框第 ① 项是 **`① 从哪儿开始`**（`本会话「最后聊完的那一轮」为止（第 N 轮末 · 共 M 条）—— 平台自己算的，改不了`）

   - **每个输入栏都写明「你写的东西去哪儿」**（用户 2026-10-02 问：「备注是只给人看的，还是会进 agent 上下文？」）：

     开子会话首条任务 = `会成为子会话的第一句话 —— 它的模型看得到`；发消息 = `会成为子会话的一个新轮次`；
     派活 = `写进那位成员的收件箱`。**四栏文案各不相同**，不许再用一句"会写进记录"盖住所有框

   - **凡是能写字的地方都带一个两态标记**（用户 2026-10-02：「整个 Demo 都存在这个问题：哪些编辑了模型能看到、哪些看不到」）：

## 趋势区怎么用（M05-16 重做后）

参照参考插件 `dsh-context` 的 `trendChart` 设计：

| 控件 | 说明 |
|---|---|
| **按轮次 / 按步骤** | 一轮一根柱（合并各步、标步数）／一次请求一根柱。标题会写出规模：`按轮次（共 28 轮）`、`按步骤（共 72 次请求）` |
| **总计 / 增量** | 该次请求的上下文量 ／ 比上一次多了多少。**柱体按类别分色堆叠**（颜色 = 右侧分类树的类别、段高 = 该类占比）；增量模式**围绕零线**：涨的段在零线**上方**、跌的段在**下方**，**颜色仍是类别**（不再"变红"） |
| **自适应** | 纵轴上限只按**当前可见的柱子**算 → 长会话里远处的尖峰不会把眼前的柱子压平 |
| **点色块** | 分类树里某一类的色块 = 趋势图只画那一类（再点恢复"全部"） |
| **点柱子** | 按轮次：选中该轮（右侧切到**末步**）；按步骤：选中那一步 |
| **刻度带** | 按步骤模式下柱子下面的轮号分组带，格宽 = 该轮步数；点一格 = 选该轮末步 |

## 移动端适配（M05-17）

参照参考插件：**没有一处 `@media` 管主布局**，靠流式与容器查询。

- 两列用 `flex: 1 1 min(420px, 100%)` → 窄屏自动单列，宽屏自然两列
- 卡片 `container-type: inline-size`，内部用 `@container` 改排布（太窄时隐藏纵轴、统计卡改 2 列、行上标签隐藏）
- `@media (pointer: coarse)`（真触屏）把可点区域提到 **≥44px**；桌面窄窗口不算触屏
- 底部按钮/抽屉/弹窗避开 iPhone 手势条（`env(safe-area-inset-*)`）
- 页面本身不横向滚：横向滚动只发生在卡片内部

## 讲解模式的正确用法（M05-22）

- 开着讲解模式时，**序号 ≠ 按钮**：
  - **点左上角小圆圈序号** → 右侧推出讲解卡（它是做什么的 / 会发生什么 / 能不能撤回 / 要不要确认 / 对应哪条 R）
  - **点按钮本身** → 照常执行它自己的交互（例如「编辑」就真的打开编辑器、「应用」就真的弹确认框）
- 序号是**真实节点**（不是 CSS 伪元素 —— 伪元素点不到），所以它既能点、也能用键盘 `Tab`/`Enter` 触达。
- 序号自己带说明（悬停可见）：`#12 编辑（遮蔽原文） —— 点这里看说明（不影响按钮本身）`。
- 关掉讲解模式 → 序号全部清理，按钮恢复原样。
