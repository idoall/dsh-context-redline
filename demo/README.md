# 交互原型（demo）· 怎么用 / 怎么提意见

> **这不是插件代码**，是一个**可点击的规格书**：把 [`docs/03`](../docs/03-ui-spec.md) 的交互逐条做出来给你点。
> 全部数据是假的、全部动作只改本地状态 —— **不发任何请求、不碰你的真实会话**。

## 打开

```bash
# 仓库根目录执行（已在本机起好服务时不用再跑）
python3 -m http.server 5180 --bind 0.0.0.0 --directory demo
```

- 本机：<http://127.0.0.1:5180/redline-panel.html>
- 局域网（手机/其它设备，若防火墙允许）：<http://10.0.0.30:5180/redline-panel.html>

| 重来 | **重置原型** |

## 顶栏那排状态开关（**最重要的验货工具**）

它们模拟宿主的真实状态，**切换后按钮可见性与文案必须按规范立刻变化**：

| 开关 | 关掉/打开会看到什么 | 依据 |
|---|---|---|
| **轮次未结束** | 写会话类按钮**全部不出现**；本地可逆写入（草稿/冻结/固定块）仍可用；顶部出现说明条 | R4.4 / R2.3 |
| **会话在本进程**（关掉） | 整列动作条禁用 + 说明条；版本历史仍可只读 | R4.4 / R4.6 |
| **官方团队可用**（关掉） | `派活` / `建成官方任务` / 团队成员式`打断` **全部消失**（不是报错）；下方团队区块变成一行"未启用" | `docs/01` F32 / `docs/06` §3.2 |
| **子会话正忙**（打开）| 点`压缩` → 被人话拒绝：*"子会话正在运行，等它空闲再压缩。（busy）"* | `docs/06` §5 |
| **草稿 N 条**（点一下）| 加一条演示草稿 → 行上出现`未生效`、**吸顶条**出现、`应用到会话`按钮才出现 | R4.1 / R5.2 |
| **回流未确认** | 下方"待处理的结果"从"已收到结算通知"切成 **回流未确认**（父 Agent 当时不在进程 → 平台不投递） | R5.1 第 4 项 / `docs/01` F12.1 |

## 请重点验这几处（也是我最怕做错的地方）

1. **一行上到底该有哪些按钮** —— 展开 `用户消息` 类，逐条看：
   - `#1240` 原始节点 → `编辑` + `批注`；
   - `#1301` **替换体（当前可见）** → **仍有`编辑`**（可连续改）+ `版本历史`；
   - `#1287` **已被遮蔽的原文** → **没有`编辑`**，给一句原因 + `版本历史`；
   - `#1293` **助手消息** → **只给`批注`** + 原因（平台两条规则互斥）；
   - `#1295` **工具结果** → `编辑`（只改内容文本/错误标记）；
   - `#1297` **注入内容** → `编辑` + `批注` + `存为不变量`；
   - `#1303` **被压缩埋掉** → 只能批注。 → 依据 `docs/03` R2.2 / R4.6
2. **草稿 → 应用 → 版本历史 → 恢复** 整条链（这是图 2 ④ 的核心）：
   在 `#1240` 点`编辑` → 改几个字 → `保存草稿` → 行上出现`未生效` → `应用到会话`（**确认框里有本次清单**）→ 原文变`已被 #1300 接替`、出现新条目 → 点`版本历史` → 选"原始" → `从这一版恢复`（**二次确认**）→ 行上多出回滚关系。
3. **文案是否说人话**：每个确认框的**短警示**（会发生什么/能不能撤回）+ **本次清单**。觉得哪句别扭，直接告诉我改哪句。
4. **快照与子会话**：`冻结当前位置` → `开子会话`（确认框五项，你要写首条任务）→ 索引行上的 `派活 / 建成官方任务 / 压缩 / 打断`（各自确认框不同）→ 团队区块只读。
5. **窄屏**：把窗口拖到 ~640px 宽，看有没有横向滚动、按钮是否还在一行里挤。

## 趋势区怎么用（M05-16 重做后）

参照参考插件 `dsh-context` 的 `trendChart` 设计：

| 控件 | 说明 |
|---|---|
| **按轮次 / 按步骤** | 一轮一根柱（合并各步、标步数）／一次请求一根柱。标题会写出规模：`按轮次（共 28 轮）`、`按步骤（共 72 次请求）` |
| **总计 / 增量** | 该次请求的上下文量 ／ 比上一次多了多少。**增量可为负**（压缩/裁剪后变小，向下画且变红） |
| **自适应** | 纵轴上限只按**当前可见的柱子**算 → 长会话里远处的尖峰不会把眼前的柱子压平 |
| **点色块** | 分类树里某一类的色块 = 趋势图只画那一类（再点恢复"全部"） |
| **点柱子** | 按轮次：选中该轮（右侧切到**末步**）；按步骤：选中那一步 |
| **刻度带** | 按步骤模式下柱子下面的轮号分组带，格宽 = 该轮步数；点一格 = 选该轮末步 |
| **步级快捷片** | `第 1 步 / 第 2 步 / … / 当前（下一次请求）`；还有 `◀ 上一轮 / 下一轮 ▶`、`上一步 / 下一步`（`←/→` 也行） |
| **✂** | 压缩/裁剪标记挂在它之后的第一个请求上 |
| **回到当前** | 一键滚到最右（最新一次请求） |

演示数据是 **28 轮 / 72 次请求**，柱宽固定 14px → 轮数多时**横向滚动**，不会压缩到看不清。
手机上滑到趋势图两端**不会**触发浏览器"左滑返回"（`overscroll-behavior-x: contain` + wheel 兜底）。

## 移动端适配（M05-17）

参照参考插件：**没有一处 `@media` 管主布局**，靠流式与容器查询。

- 两列用 `flex: 1 1 min(420px, 100%)` → 窄屏自动单列，宽屏自然两列
- 卡片 `container-type: inline-size`，内部用 `@container` 改排布（太窄时隐藏纵轴、统计卡改 2 列、行上标签隐藏）
- `@media (pointer: coarse)`（真触屏）把可点区域提到 **≥44px**；桌面窄窗口不算触屏
- 底部按钮/抽屉/弹窗避开 iPhone 手势条（`env(safe-area-inset-*)`）
- 页面本身不横向滚：横向滚动只发生在卡片内部

## 没有浏览器工具时怎么自检（M05-18）

本机已彻底删除 browser-skill / `bsk` → 助手**没有浏览器工具**，所以自检改成：

```bash
node demo/check-static.mjs      # 契约：id 是否都存在、class 是否有样式、每个可交互元素是否有讲解词
node demo/check-runtime.mjs     # 冒烟：用最小 DOM 桩真的执行 demo.js，跑渲染/切换/应用/回滚，22 项断言
node demo/build-standalone.mjs  # 重新打包单文件版（改完 css/js 必须跑）
bash demo/serve.sh             # 起本地静态服务（bash demo/serve.sh stop 停止）
```

**主观判断（好不好用、好不好看）只有你能给**：打开页面 → 右上角 `自测面板`（自报盒子尺寸/横向溢出/趋势柱数与刻度）→ 再看手感。


## 讲解模式的正确用法（M05-22）

- 开着讲解模式时，**序号 ≠ 按钮**：
  - **点左上角小圆圈序号** → 右侧推出讲解卡（它是做什么的 / 会发生什么 / 能不能撤回 / 要不要确认 / 对应哪条 R）
  - **点按钮本身** → 照常执行它自己的交互（例如「编辑」就真的打开编辑器、「应用」就真的弹确认框）
- 序号是**真实节点**（不是 CSS 伪元素 —— 伪元素点不到），所以它既能点、也能用键盘 `Tab`/`Enter` 触达。
- 序号自己带说明（悬停可见）：`#12 编辑（遮蔽原文） —— 点这里看说明（不影响按钮本身）`。
- 关掉讲解模式 → 序号全部清理，按钮恢复原样。
