# 交互原型（demo）· 怎么用 / 怎么提意见

> **这不是插件代码**，是一个**可点击的规格书**：把 [`docs/03`](../docs/03-ui-spec.md) 的交互逐条做出来给你点。
> 全部数据是假的、全部动作只改本地状态 —— **不发任何请求、不碰你的真实会话**。

## 打开

```bash
# 仓库根目录执行（已在本机起好服务时不用再跑）
bash demo/serve.sh status       # 是否在跑
bash demo/serve.sh              # 起服务（**后台常驻**，跟这个终端退不退出无关）
bash demo/serve.sh stop         # 停
bash demo/serve.sh fg           # 要前台跑、Ctrl-C 停，用这个
```

- 本机：<http://127.0.0.1:5180/redline-panel.html>
- 局域网（手机/其它设备，若防火墙允许）：<http://10.0.0.30:5180/redline-panel.html>
- 单文件独立版（内联 css/js，**连服务都不用**、可 file:// 双击 / AirDrop 到手机）：
  [`redline-panel.standalone.html`](redline-panel.standalone.html) 或
  <http://10.0.0.30:5180/redline-panel.standalone.html>

> **怎么确认你看到的是最新版**：页头那颗标签写着 **`交互原型 v1 · 单文件版 <指纹>`**（7 位）
> —— 那是 `demo.css + demo.js` 的 sha256 前 7 位。改完 css/js 必须跑
> `node demo/build-standalone.mjs` 才会同步；**忘了跑会被 `check-static.mjs` 抓成红的**。
> 把那个指纹告诉我，我就能确认你手上是哪一版。
>
> 服务由 [`serve.py`](serve.py) 提供，统一发 `Cache-Control: no-store`（照旧是只读、不写盘）——
> 刷新就是最新版。之前用 `python3 -m http.server` 时不发这个头，浏览器会把**没有查询串**的
> 单文件版缓存起来，让人以为改动没生效（2026-09-30 实际发生过一次）。
>
> **它是守护进程，不是 shell 后台任务**：以前用 `nohup … &` / 终端后台任务起，父进程一收工服务就没了
> —— 表现就是"刚才还能开，现在打不开了"（2026-09-30 发生过）。现在 `serve.py --daemon` 用双 fork + setsid
> 脱离会话（`ps` 里 PPID=1、无控制终端），pidfile 在**端口绑定成功之后**才写，日志在
> `/tmp/redline-demo-5180.log`。**重启电脑后需要重新 `bash demo/serve.sh` 一次**。

4. **子会话**（卡内按内容分成**四块**：开子会话 / 子会话索引 / 待处理的结果 / 官方团队；

## 趋势区怎么用（M05-16 重做后）

参照参考插件 `dsh-context` 的 `trendChart` 设计：

| 控件 | 说明 |
|---|---|
| **按轮次 / 按步骤** | 一轮一根柱（合并各步、标步数）／一次请求一根柱。标题会写出规模：`按轮次（共 28 轮）`、`按步骤（共 72 次请求）` |
| **总计 / 增量** | 该次请求的上下文量 ／ 比上一次多了多少。**柱体按类别分色堆叠**（颜色 = 右侧分类树的类别、段高 = 该类占比）；增量模式**围绕零线**：涨的段在零线**上方**、跌的段在**下方**，**颜色仍是类别**（不再"变红"） |
| **自适应** | 纵轴上限只按**当前可见的柱子**算 → 长会话里远处的尖峰不会把眼前的柱子压平 |
| **点色块** | 分类树里某一类的色块 = 趋势图只画那一类（再点恢复"全部"） |
| **点柱子** | 按轮次：选中该轮（右侧切到**末步**）；按步骤：选中那一步 |
| **刻度带** | 按步骤模式下柱子下面的轮号分组带，格宽 = 该轮步数；点一格 = 选该轮末步 |
| ~~**步级快捷片 / 顺序导航**~~ | **已按你的意见删除**（2026-10-01）：柱体 hover 就报"第几轮 · 第几步"、点一下即选中，那一排只是重复信息。柱子下面那行**轮号刻度带保留**（它是坐标轴）；要按步选择仍可用右侧的步骤下拉 |
| **回到当前** | 一键滚到最右（最新一次请求） |

手机上滑到趋势图两端**不会**触发浏览器"左滑返回"（`overscroll-behavior-x: contain` + wheel 兜底）。

## 移动端适配（M05-17）

参照参考插件：**没有一处 `@media` 管主布局**，靠流式与容器查询。

- 两列用 `flex: 1 1 min(420px, 100%)` → 窄屏自动单列，宽屏自然两列
- 卡片 `container-type: inline-size`，内部用 `@container` 改排布（太窄时隐藏纵轴、统计卡改 2 列、行上标签隐藏）
- `@media (pointer: coarse)`（真触屏）把可点区域提到 **≥44px**；桌面窄窗口不算触屏
- 底部按钮/抽屉/弹窗避开 iPhone 手势条（`env(safe-area-inset-*)`）
- 页面本身不横向滚：横向滚动只发生在卡片内部

## 讲解模式的正确用法（M05-22）

- 开着讲解模式时，**序号 ≠ 按钮**：
  - **点左上角小圆圈序号** → 右侧推出讲解卡（它是做什么的 / 会发生什么 / 能不能撤回 / 要不要确认 / 对应哪条 R）
  - **点按钮本身** → 照常执行它自己的交互（例如「编辑」就真的打开编辑器、「应用」就真的弹确认框）
- 序号是**真实节点**（不是 CSS 伪元素 —— 伪元素点不到），所以它既能点、也能用键盘 `Tab`/`Enter` 触达。
- 序号自己带说明（悬停可见）：`#12 编辑（遮蔽原文） —— 点这里看说明（不影响按钮本身）`。
- 关掉讲解模式 → 序号全部清理，按钮恢复原样。
