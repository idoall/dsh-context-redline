# Context Redline v0.2.0 — head-and-tail anchor

<h3 id="cn-v0.2.0">新增：首尾锚点</h3>

- 插件版本：`0.2.0`。支持 DSH `>=0.2.2-rc.5 <0.3.0-0`，针对 `0.2.2-rc.5` 构建与回归验证；要求 Node.js `>=24.9.0`。旧版 DSH 可继续使用插件 `0.1.3`。
- 确认框新增可选的「锚点」：写一小段关键词或硬约束。插件把它原样放在首条消息的**开头**（任务之后）和**结尾**（迁移内容之后）各一次，用来抵抗长会话里的注意力稀释。
- 锚点完全由人书写，不调用任何模型、不做摘要或改写；它出现在确认框、最终发送全文和确认指纹里，改动锚点会让旧确认失效。它不会写进系统提示词或工具定义（那些归目标预设所有），也不改写来源会话。
- 没有填写锚点时，首条消息与 `0.1.3` 逐字节相同。
- 保留 0.1.1–0.1.3 的行为修复：读取会话当前模型与预设、等待异步投影注册并使用保留句柄、保留新版工具结果历史正文与错误状态。
- 同步中英文 README、CHANGELOG、支持范围与 npm 包内容；GitHub Release 仍等待 npm 发布成功后创建。
- 不包含未验收的体检功能、carrier-seed 实验或其他本地未发布改动；不重写来源会话。自动化回归、构建和包检查不等于生产界面 / 真实会话人工验收，本次未执行生产重启或安装。

示例（用户填写任务与锚点后生成的首条消息）：

```text
把设置页改成深色模式，并补齐移动端断点。

【锚点】
必须用 TypeScript；不要修改公开接口；完成后运行 pnpm test。

以下是经你确认后迁移到这个零历史新会话的上下文。……

【#11 · 原角色：user · user/message】
……

【锚点重申】
必须用 TypeScript；不要修改公开接口；完成后运行 pnpm test。
```

```sh
dsh plugin --profile web add dsh-context-redline@0.2.0
```

如安装结果提示需要重启，由用户本人重启 `dsh web`。

<h3 id="en-v0.2.0">New: head-and-tail anchor</h3>

- Plugin version: `0.2.0`. Supports DSH `>=0.2.2-rc.5 <0.3.0-0`, built and regression-tested against `0.2.2-rc.5`; requires Node.js `>=24.9.0`. Older DSH users can stay on plugin `0.1.3`.
- The confirmation box adds an optional **anchor**: a short set of keywords or hard constraints. The plugin places it verbatim at the **start** of the first message (after the task) and again at the **end** (after the migrated material), to resist attention dilution in long conversations.
- The anchor is entirely human-written; no model call, summary or rewrite. It appears in the confirmation box, the final message and the confirmation fingerprint, so changing it invalidates an old confirmation. It never enters the system prompt or tool definitions (owned by the target preset) and never rewrites the source session.
- With an empty anchor, the first message is byte-identical to `0.1.3`.
- Retains the 0.1.1–0.1.3 fixes: current model/preset reads, asynchronous projection registration with the retained handle, and current tool-result history content and failure status.
- Synchronizes both READMEs, the changelog, the support range and npm package contents. The GitHub Release still waits for successful npm publication.
- Excludes unaccepted diagnostics, carrier-seed experiments and other unpublished local work; source sessions remain append-only. Automated regression, build and package checks are not production visual or real-session manual acceptance. No production restart or installation was performed.

Example (the first message produced from a human-written task and anchor):

```text
Turn the settings page dark and complete the mobile breakpoints.

【锚点】
TypeScript only; do not change public interfaces; run pnpm test when done.

以下是经你确认后迁移到这个零历史新会话的上下文。……

【#11 · 原角色：user · user/message】
……

【锚点重申】
TypeScript only; do not change public interfaces; run pnpm test when done.
```

```sh
dsh plugin --profile web add dsh-context-redline@0.2.0
```

If installation reports that a restart is required, restart `dsh web` yourself.
