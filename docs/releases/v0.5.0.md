# Context Redline v0.5.0 — trend duration overlay

<h3 id="cn-v0.5.0">新增：趋势耗时曲线 + 交互同步</h3>

- 插件版本：`0.5.0`。支持 DSH `>=0.2.2-rc.5 <0.3.0-0`，针对 `0.2.2-rc.5` 构建与回归验证；要求 Node.js `>=24.9.0`。旧版 DSH 可继续使用插件 `0.4.1`。
- 趋势卡新增「耗时」开关：每一步的活跃耗时（step 窗口减去审批/提问等待）画成柱子上的曲线，读右侧刻度；按轮次时把该轮各步相加，缺失该值的柱子会断开曲线而不是伪造一个点。
- 宿主在 `step/end` 把 `activeMs` 写到该步已提交的请求记录上；审批等待（`approval/asked` → `approval/decided`）与 `ask_user_question` 的工具窗口会从步窗口里扣除，重叠等待按并集计算。
- 标题里的自适应与耗时合并为一组紧凑开关；移除聚焦分类的旧副标题；移植参考插件的 hover 性能修复（悬浮路径不再强制同步布局）。
- 持久化状态版本递增（23 → 24）：旧缓存行会从日志重新折叠，补回耗时字段。
- 同步更新 README 总览截图（趋势卡现在带耗时曲线）。中英文 README、CHANGELOG、支持范围与 npm 包内容保持一致。
- 不包含 DNA 趋势指纹模式、未验收的体检功能或 carrier-seed 实验。自动化回归、构建和包检查不等于生产界面 / 真实会话人工验收，本次未执行生产重启或安装。

```sh
dsh plugin --profile web add dsh-context-redline@0.5.0
```

<h3 id="en-v0.5.0">New: trend duration overlay + interaction sync</h3>

- Plugin version: `0.5.0`. Supports DSH `>=0.2.2-rc.5 <0.3.0-0`, built and regression-tested against `0.2.2-rc.5`; requires Node.js `>=24.9.0`. Older DSH users can stay on plugin `0.4.1`.
- The trend card gains a **Duration** toggle: each step’s active time (step window minus approval / Q&A waits) is drawn as a curve over the bars, read off the right-hand axis. Turn mode sums the turn’s steps; a bar without the figure breaks the line instead of faking a point.
- The Host stamps `activeMs` at `step/end` onto that step’s committed request; approval waits (`approval/asked` → `approval/decided`) and the `ask_user_question` tool window are subtracted, with overlapping waits priced as their union.
- Adaptive and Duration share one compact title group; the focused-category subtitle is removed; the reference plugin’s hover-path performance fix is ported (no forced synchronous layout on hover).
- The persisted state version is bumped (23 → 24): cached rows refold from the log and regain the duration field.
- The README overview screenshot is regenerated (the trend card now shows the duration curve). Both READMEs, the changelog, the support range and npm package contents stay synchronized.
- Excludes the DNA trend fingerprint mode, unaccepted diagnostics and carrier-seed experiments. Automated regression, build and package checks are not production visual or real-session manual acceptance. No production restart or installation was performed.

```sh
dsh plugin --profile web add dsh-context-redline@0.5.0
```
