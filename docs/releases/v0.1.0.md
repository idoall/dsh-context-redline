# 上下文批改 v0.1.0（首版）

兼容 DSH `0.2.1-alpha.2`（`engines.dsh`：`>=0.2.1-alpha.2 <0.3.0`）。

<h3 id="cn-v0.1.0">✨ 新增</h3>

- **看清并批改上下文。** 查看当前 surface 的完整文本，逐条编辑或删除，保存只写插件本地。
- **零历史普通新会话。** 在当前工作区创建普通根会话，只携带你确认的迁移材料。
- **最终发送全文。** 确认框中的文本就是新会话收到的完整第一条用户消息，可直接改。
- **会话级模型与推理等级。** 一行浮动选择器只配置新会话，不改来源会话或全局默认。
- **自动回程。** 任务完成后，绑定结果原样回到来源会话。
- **崩溃恢复。** 固定 ID、持久台账、精确正文匹配与三态恢复；未知状态不重发。
- **图片如实处理。** 混合图文消息迁移文字并显示遗漏图片数；未知媒体明确拒绝。

### 安装

```sh
dsh plugin --profile web add dsh-context-redline@latest
```

安装或宿主更新后，由你本人重启 `dsh web`。

# Context Redline v0.1.0 (first release)

Works with DSH `0.2.1-alpha.2` (`engines.dsh`: `>=0.2.1-alpha.2 <0.3.0`).

<h3 id="en-v0.1.0">✨ Added</h3>

- **Inspect and redline context.** Read the full current surface, edit or delete items, and keep every save local to the plugin.
- **Zero-history ordinary session.** Opens a root session in the current workspace carrying only the confirmed migration material.
- **Authoritative final message.** The confirmation textarea is the exact first user message the new session receives.
- **Per-session model and effort.** A compact floating picker configures only the carrier, never the source or global default.
- **Automatic verbatim return.** The bound result returns to the source session when the task finishes.
- **Crash recovery.** Fixed IDs, durable ledgers, exact-content matching, and three-state recovery; unknown never resends.
- **Honest image handling.** Mixed text/image messages migrate text and report omitted images; unknown media refuses.

### Install

```sh
dsh plugin --profile web add dsh-context-redline@latest
```

Restart `dsh web` yourself after installation or Host updates.
