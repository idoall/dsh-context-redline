# Context Redline v0.8.2 — mandatory task decomposition

<h3 id="cn-v0.8.2">技能升级：强制拆任务，禁止单会话连续做多个里程碑</h3>

- 插件版本：`0.8.2`。支持 DSH `>=0.2.2-rc.5 <0.3.0-0`，针对 `0.2.2-rc.5` 构建与回归验证；要求 Node.js `>=24.9.0`。旧版 DSH 可继续使用插件 `0.8.1`。
- `context-redline-handoff` 技能现在把“拆任务”写成硬规则：
  - 首条任务从“读计划、建立任务清单、把第一个任务派给子会话”开始，不得直接写代码；
  - 每个里程碑 / 交付物一个独立任务，每个任务至少一个子会话或团队成员；
  - 主会话只规划、分派、审查，不直接开发、修改或测试；不得自己连续做多个任务 / 多个里程碑；
  - 即使你说“过程中不用确认”，任务拆分与成果审查也不取消，只取消逐里程碑的用户确认；
  - 验收必须包含任务清单、每个任务的子会话产物、主会话审查记录；出现“单会话连续完成多个里程碑”判不合格。
- 保留 0.8.1 的主会话/子会话分工与按需有头 UAT；不新增宿主字段、不调用模型、不写会话；持久化状态保持 24。
- 自动化回归、构建和包检查不等于生产界面 / 真实会话人工验收；本次未执行生产重启或安装。

```sh
dsh plugin --profile web add dsh-context-redline@0.8.2
```

<h3 id="en-v0.8.2">Skill upgrade: mandatory task decomposition</h3>

- Plugin version: `0.8.2`. Supports DSH `>=0.2.2-rc.5 <0.3.0-0`, built and regression-tested against `0.2.2-rc.5`; requires Node.js `>=24.9.0`. Older DSH users can stay on plugin `0.8.1`.
- The `context-redline-handoff` skill now makes task decomposition a hard rule:
  - The first task starts with “read the plan, build a task list, dispatch the first task to a subagent”, never with coding;
  - One independent task per milestone/deliverable, each with at least one subagent or team member;
  - The main session only plans, dispatches and reviews; it never develops, modifies or tests directly, and never runs several tasks/milestones itself;
  - Even when you say “no confirmation during the process”, decomposition and review stay; only the per-milestone user confirmation is waived;
  - Acceptance must include the task list, each task's subagent output and the main session's review record; a “single session completed several milestones” path fails.
- Retains the 0.8.1 main/subagent separation and conditional headed UAT; no host field, model call or session write; persisted state stays at version 24.
- Automated regression, build and package checks are not production visual or real-session manual acceptance. No production restart or installation was performed.

```sh
dsh plugin --profile web add dsh-context-redline@0.8.2
```
