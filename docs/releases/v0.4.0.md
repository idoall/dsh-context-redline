# Context Redline v0.4.0 — anchored conversation

<h3 id="cn-v0.4.0">新增：不迁移上下文、只带目标的锚定会话</h3>

- 插件版本：`0.4.0`。支持 DSH `>=0.2.2-rc.5 <0.3.0-0`，针对 `0.2.2-rc.5` 构建与回归验证；要求 Node.js `>=24.9.0`。旧版 DSH 可继续使用插件 `0.3.0`。
- 批改面板新增「新建带规则的对话」：不迁移当前上下文，直接创建一个独立普通 root 会话。
- 确认框分四段：首条任务、目标、验收标准、执行纪律。目标默认跟随首条任务，可直接改。
- 目标/验收/纪律组成一条冻结的运行时快照，通过 `systemPrompt.context` 只注册给这个新会话；任务不重复进快照。快照在确认前逐字展示，创建后冻结。
- 快照文本不变时不会重复写入；压缩折叠后 DSH 会自动重新声明，并声明取代旧版本（包括摘要里的残留）。
- 没有回程：新会话是独立对话，结果不自动回到来源会话。重试使用同一个 `operationId`，只会创建/投递一次。
- 不迁移上下文、不读取/改写来源会话日志、不改动其他新对话；入口只在批改面板里，不改变 DSH 原生「新建对话」。
- 保留 0.1.x–0.3.0 的修复与两种锚点模式；同步中英文 README、CHANGELOG、支持范围与 npm 包内容。
- 不包含未验收的体检功能、carrier-seed 实验或其他本地未发布改动。自动化回归、构建和包检查不等于生产界面 / 真实会话人工验收，本次未执行生产重启或安装。

```sh
dsh plugin --profile web add dsh-context-redline@0.4.0
```

<h3 id="en-v0.4.0">New: anchored conversation without context migration</h3>

- Plugin version: `0.4.0`. Supports DSH `>=0.2.2-rc.5 <0.3.0-0`, built and regression-tested against `0.2.2-rc.5`; requires Node.js `>=24.9.0`. Older DSH users can stay on plugin `0.3.0`.
- The redline panel adds **New conversation with rules**: an independent ordinary root session, created without migrating the current context.
- The confirmation has four parts: first task, goal, acceptance criteria and discipline. The goal follows the first task by default and stays editable.
- Goal, acceptance and discipline form one frozen runtime snapshot, registered through `systemPrompt.context` for that new conversation only. The task is not repeated in the snapshot. The exact text is shown before creation and frozen afterwards.
- Unchanged snapshot text is not rewritten; after compaction folds it, DSH re-declares it with an explicit supersession notice (including retained summaries).
- No return path: the new conversation is independent and its result does not come back to the source session. Retrying with the same `operationId` creates and delivers only once.
- No context migration, no source-log read/write, no effect on other new conversations; the entry lives in the redline panel and leaves DSH's native **New conversation** untouched.
- Retains the 0.1.x–0.3.0 fixes and both anchor modes; synchronizes both READMEs, the changelog, the support range and npm package contents.
- Excludes unaccepted diagnostics, carrier-seed experiments and other unpublished local work. Automated regression, build and package checks are not production visual or real-session manual acceptance. No production restart or installation was performed.

```sh
dsh plugin --profile web add dsh-context-redline@0.4.0
```
