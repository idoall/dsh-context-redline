# Context Redline v0.1.1 — DSH 0.2.2 compatibility

<h3 id="cn-v0.1.1">兼容性修复</h3>

- 插件版本：`0.1.1`。支持 DSH `>=0.2.2-rc.1 <0.3.0-0`，针对 `0.2.2-rc.1` 构建与回归验证；要求 Node.js `>=24.9.0`。旧 DSH 用户请暂留插件 `0.1.0`，本次不支持 DSH `0.3.0` 预发布版。
- 模型配置读取会话当前选择，修复切换模型后预览仍使用启动时旧模型 / 推理等级的问题；恢复承载会话时同样核对当前实际模型，未知或不一致时停止，不自动改模型。
- 预设读取会话当前已记录的选择，不再优先使用创建时的固定头信息；未知预设不猜测。
- 等待异步会话投影注册完成，详情读取使用保留的投影句柄，注册失败不会被当成激活成功。
- 修复新版工具结果历史详情的正文、调用配对与错误状态丢失，继续支持旧日志格式。
- 同步中英文 README、支持范围、开发依赖与 npm 包内容。GitHub Release 等待 npm 发布成功后创建。
- 这是从已发布产品基线制作的兼容性补丁，不包含未验收的体检功能、carrier-seed 实验或其他本地未发布改动。不重写来源会话；真实投递仍须用户确认。
- 自动化回归、构建和包检查不等于生产界面 / 真实会话人工验收，本次未执行生产重启或安装。

```sh
dsh plugin --profile web add dsh-context-redline@0.1.1
```

如安装结果提示需要重启，由用户本人重启 `dsh web`。

<h3 id="en-v0.1.1">Compatibility fixes</h3>

- Plugin version: `0.1.1`. Supports DSH `>=0.2.2-rc.1 <0.3.0-0`, built and regression-tested against `0.2.2-rc.1`; requires Node.js `>=24.9.0`. Older DSH users should keep plugin `0.1.0` until upgrading DSH. DSH `0.3.0` prereleases are excluded.
- Read the Session's current model selection rather than startup options. Carrier previews no longer inherit a stale route or reasoning effort after a model switch. Recovery validates the effective route and refuses mismatched or unknown selections without changing the model.
- Read the Session's recorded preset selection instead of its immutable creation header; an unknown preset stays unknown.
- Await asynchronous projection registration and retain the ready projection handle for detail reads. Registration failure must not appear as successful activation.
- Preserve current tool-result history content, call pairing and failure status while keeping legacy log reads compatible.
- Synchronize both READMEs, support metadata, development dependencies and npm package contents. Create the GitHub Release only after successful npm publication.
- This compatibility-only patch is based on the published product, excluding unaccepted diagnostics, carrier-seed experiments and other unpublished local work. Source sessions remain append-only; real delivery still requires human confirmation.
- Automated regression, build and package checks are not production visual or real-session manual acceptance. No production restart or installation was performed for this release.

```sh
dsh plugin --profile web add dsh-context-redline@0.1.1
```

If installation reports that a restart is required, restart `dsh web` yourself.
