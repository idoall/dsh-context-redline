# Context Redline v0.9.5 — guard that tracks progress, and head/tail anchors

<h3 id="cn-v0.9.5">守卫不再被「写审查记录」卡死；加入首尾短锚点</h3>

- 插件版本：`0.9.5`。支持 DSH `>=0.2.3-alpha.2 <0.3.0-0`，针对 `0.2.3-alpha.2` 构建与回归验证；要求 Node.js `^24.22.3 || >=26.13.1`。旧版 DSH 可继续使用插件 `0.9.4`。
- 修的真实问题（来自 `session-anchor-c3075660…`）：主会话按验收要求写自己的计划 / 审查记录，守卫却把 `write`/`edit` 一律算违规，于是每轮直接短路成 `fail`，**评估器从未运行、`current` 永远停在 T1**；卡片上的「主会话直接写文件或执行了命令」是误报（它写的是 `reports/review/T1-审查…` 和任务清单，唯一 `bash` 是 `ls`）。
- 修复：
  - 只观察模式**每轮都跑评估器**，不再用工具计数短路；候选里带上 `main_write_paths`（写入路径，不只是次数），由评估器判断「只写自己的记录可以接受、写业务代码或执行命令属于违规」；
  - 判定通过就推进 `current`；未通过只记尝试次数，不锁死台账；
  - 卡片新增「**评估未运行：原因**」，区分「评估器没跑」与「判定 fail」。
- 新增**首尾短锚点（第一层高遵循注入）**：完整目标卡（order 96）之外，把一段约 1KB 的不变量注入到每轮提示的**头部（order 90）**和**尾部（order 900）**——目标 hash、当前任务与验收、进度、最近判定与纠正、硬规则、停止条件，文本来自实时台账、每轮刷新。长文要经过「读到摘要」和「长上下文压缩」两级，必然走样；短锚点每轮贴首尾、链路最短，负责让关键约束不走样。
- 守卫仍然**只观察**：不拦工具、不 steer、不结束轮次；拦截路径留待下一版。
- 自动化回归、构建与包检查不等于生产界面人工验收；本次未执行生产重启或安装。

```sh
dsh plugin --profile web add dsh-context-redline@0.9.5
```

<h3 id="en-v0.9.5">The guard tracks progress again; head and tail anchors added</h3>

- Plugin version: `0.9.5`. Supports DSH `>=0.2.3-alpha.2 <0.3.0-0`, built and regression-tested against `0.2.3-alpha.2`; requires Node.js `^24.22.3 || >=26.13.1`. Older DSH users can stay on plugin `0.9.4`.
- The real defect (seen in `session-anchor-c3075660…`): the main session must write its own plan/review records, but the guard counted every `write`/`edit` as a violation and short-circuited to `fail`, so the **evaluator never ran and `current` stayed at T1**; the card's “main session wrote a file or ran a command” was a false positive (it wrote its own `reports/review/…` record and task list, and the only `bash` call was `ls`).
- Fix:
  - observe mode **runs the evaluator every turn** and no longer short-circuits on a tool count; the candidate now carries `main_write_paths`, and the evaluator judges “writing its own records is acceptable, writing business code or running commands is a violation”;
  - a pass advances `current`; a miss only records an attempt, so the ledger no longer pins;
  - the card reports **“Evaluation did not run: reason”**, separating “not evaluated” from a real `fail`.
- New **head/tail short anchor** (first high-obedience layer): beside the full goal card (order 96), a ~1KB invariant block is injected at the **head (order 90)** and **tail (order 900)** of every prompt — goal hash, current task and acceptance, progress, last verdict and correction, hard rules, stop conditions — refreshed from live state each turn. Long documents pass through “read and summarise” and “long-context compaction”; the short anchor sits at the edges with the shortest chain and keeps the invariants from drifting.
- The guard is still **observe-only**: no tool blocking, no steering, no turn stopping; enforcement stays for the next version.
- Automated regression, build and package checks are not production visual acceptance. No production restart or installation was performed.

```sh
dsh plugin --profile web add dsh-context-redline@0.9.5
```
