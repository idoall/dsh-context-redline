# Context Redline v0.8.1 — handoff discipline and session title

<h3 id="cn-v0.8.1">修复与规则：标题去掉“新对话”，skill 内置分工与 UAT</h3>

- 插件版本：`0.8.1`。支持 DSH `>=0.2.2-rc.5 <0.3.0-0`，针对 `0.2.2-rc.5` 构建与回归验证；要求 Node.js `>=24.9.0`。旧版 DSH 可继续使用插件 `0.8.0`。
- 锚定会话的标题直接使用「目标」，不再拼 `新对话 ·` 前缀；目标为空时退回首条任务，避免出现无意义标题。
- `context-redline-handoff` 技能内置以下规则：
  - **主会话不直接开发、修改或测试**：开发、修 bug、改测试必须派给子会话或团队成员；主会话只做规划、分派、审查。
  - 子会话说“完成”不算通过：主会话必须审查成果，发现问题打回或重新分派，不直接代改。
  - **UAT 按需判断**：涉及界面 / 交互 / 视觉的改动，必须用有头模式打开真实界面做 UAT，修正并复测到无问题才允许汇报；纯后端 / 文档改动写“无需 UAT”及理由，不硬加。
  - 验收标准里保留可检查的门：有头 UAT 的复测证据（涉及 UI 时）、主会话审查记录；执行纪律里写行为约束。
- 只改客户端标题与技能文案；不新增宿主字段、不调用模型、不写会话；持久化状态保持 24。
- 自动化回归、构建和包检查不等于生产界面 / 真实会话人工验收；本次未执行生产重启或安装。

```sh
dsh plugin --profile web add dsh-context-redline@0.8.1
```

<h3 id="en-v0.8.1">Fix and rules: no “New conversation” title prefix; skill embeds role separation and UAT</h3>

- Plugin version: `0.8.1`. Supports DSH `>=0.2.2-rc.5 <0.3.0-0`, built and regression-tested against `0.2.2-rc.5`; requires Node.js `>=24.9.0`. Older DSH users can stay on plugin `0.8.0`.
- Anchored sessions are titled by the **goal** directly, without the `新对话 ·` prefix; an empty goal falls back to the first task instead of producing a meaningless title.
- The `context-redline-handoff` skill now embeds:
  - **The main session does not develop, modify or test directly**: development, bug fixes and test changes go to subagents or team members; the main session only plans, dispatches and reviews.
  - A subagent saying “done” is not acceptance: the main session reviews the result and bounces or reassigns problems instead of fixing them directly.
  - **UAT is conditional**: UI / interaction / visual changes require headed UAT in a real interface, with fixes and retests until clean before reporting; backend/documentation changes state “no UAT needed” with a reason instead of adding it mechanically.
  - Acceptance keeps checkable gates: headed-UAT retest evidence (when UI applies) and the main session's review record; discipline carries the behavioral constraints.
- Client-side title and skill copy only; no host field, model call or session write; persisted state stays at version 24.
- Automated regression, build and package checks are not production visual or real-session manual acceptance. No production restart or installation was performed.

```sh
dsh plugin --profile web add dsh-context-redline@0.8.1
```
