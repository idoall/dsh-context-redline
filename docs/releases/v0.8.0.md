# Context Redline v0.8.0 — two handoff shapes

<h3 id="cn-v0.8.0">技能升级：同时生成迁移与锚定两种交接内容</h3>

- 插件版本：`0.8.0`。支持 DSH `>=0.2.2-rc.5 <0.3.0-0`，针对 `0.2.2-rc.5` 构建与回归验证；要求 Node.js `>=24.9.0`。旧版 DSH 可继续使用插件 `0.7.0`。
- `context-redline-handoff` 技能现在先推荐场景，再分别输出：
  - **情况 A（上下文批改 → 开启普通新会话）**：首条任务 + 锚点（选「每轮运行时规则」）；最终发送全文由插件自动拼接，不用手填；
  - **情况 B（新建带规则的对话）**：首条任务 / 目标 / 验收标准 / 执行纪律四段。
- 两种场景都按同一套规则检查：目标不缩成当前里程碑、验收可执行/可观察、未知信息标“未验证”、纪律包含出错继续与里程碑验收门。
- 技能只给文本，不建会话、不写文件、不改目标；注册仍是可选的 `ctx.inject(['skills'])`，没有 skills 服务或注册失败都不影响面板。
- 保留 0.5.0–0.7.0 的趋势、锚定会话与技能能力；同步中英文 README、CHANGELOG、支持范围与 npm 包内容。
- 自动化回归、构建和包检查不等于生产界面 / 真实会话人工验收；本次先做本地安装测试，生产重启由用户本人决定。

```sh
dsh plugin --profile web add dsh-context-redline@0.8.0
```

<h3 id="en-v0.8.0">Skill upgrade: both migration and anchored handoffs</h3>

- Plugin version: `0.8.0`. Supports DSH `>=0.2.2-rc.5 <0.3.0-0`, built and regression-tested against `0.2.2-rc.5`; requires Node.js `>=24.9.0`. Older DSH users can stay on plugin `0.7.0`.
- The `context-redline-handoff` skill now recommends a scenario first, then outputs:
  - **Case A (Context Redline → open ordinary new session)**: first task + anchor (choose **per-request runtime rule**); the final message is composed by the plugin and needs no manual fill;
  - **Case B (New conversation with rules)**: first task / goal / acceptance criteria / discipline.
- Both scenarios share the same checks: the goal is not reduced to the current milestone, acceptance is executable or observable, unknown facts are marked unverified, and discipline includes error recovery plus milestone gates.
- The skill only produces text: it creates no session, writes no file and changes no goal. Registration remains optional through `ctx.inject(['skills'])`; a missing registry or a failed registration never affects the panel.
- Retains the 0.5.0–0.7.0 trend, anchored-conversation and skill capabilities; synchronizes both READMEs, the changelog, the support range and npm package contents.
- Automated regression, build and package checks are not production visual or real-session manual acceptance; this release is tested locally first, and the user decides when to restart production.

```sh
dsh plugin --profile web add dsh-context-redline@0.8.0
```
