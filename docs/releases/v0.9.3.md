# Context Redline v0.9.3 — the anchored dialog scrolls on long forms

<h3 id="cn-v0.9.3">修复「新建带运行时规则的对话」长表单滚不动</h3>

- 插件版本：`0.9.3`。支持 DSH `>=0.2.3-alpha.2 <0.3.0-0`，针对 `0.2.3-alpha.2` 构建与回归验证；要求 Node.js `^24.22.3 || >=26.13.1`。旧版 DSH 可继续使用插件 `0.9.2`。
- 现象：填上目标守卫的字段后，弹窗高度超过屏幕；鼠标停在较高的文本框里时，滚轮 / 拖动推不动弹窗，必须点一下别处让输入框失焦、再把鼠标移回来才滚得动。
- 原因：这个弹窗用的是通用卡片（整块滚动），而里面的内容区声明了 `overscroll-behavior: contain`。文本框自己还有内部滚动，滚到尽头后手势被内容区吞掉，外层卡片收不到滚动。
- 修复：和确认框改成同一套骨架——**标题固定、内容区是唯一滚动者、底栏固定**；卡片定高 `min(740px, calc(100dvh - 28px))`、外层 `overflow: hidden`。现在光标停在任意输入框里也能把表单滚到守卫选项和「创建并进入」。
- 只改客户端样式：目标守卫、交接技能、计价与数据写入都没有变化；也不需要重新创建已有会话。
- 自动化回归、构建与包检查不等于生产界面人工验收；本次未执行生产重启或安装。

```sh
dsh plugin --profile web add dsh-context-redline@0.9.3
```

<h3 id="en-v0.9.3">Fix the anchored dialog on long forms</h3>

- Plugin version: `0.9.3`. Supports DSH `>=0.2.3-alpha.2 <0.3.0-0`, built and regression-tested against `0.2.3-alpha.2`; requires Node.js `^24.22.3 || >=26.13.1`. Older DSH users can stay on plugin `0.9.2`.
- Symptom: after filling in the Goal Guard fields the dialog grew past the viewport, and with the cursor inside one of the tall text areas the wheel or drag could not move the dialog — you had to blur the field and move the pointer back.
- Cause: the dialog used the generic card (which scrolls as a whole block) while its content area declared `overscroll-behavior: contain`. The text area kept its own internal scroll, and once it hit its end the gesture was swallowed by that content area, so the card never received it.
- Fix: the dialog now uses the confirmation dialog's skeleton — fixed header, ONE scrolling body, pinned footer — with a fixed card height `min(740px, calc(100dvh - 28px))` and `overflow: hidden` on the card. The form now scrolls to the guard options and the confirm button from anywhere, including while the cursor sits inside a field.
- Client-side CSS only: guard, handoff skill, accounting and data writes are unchanged, and existing sessions need no re-creation.
- Automated regression, build and package checks are not production visual acceptance. No production restart or installation was performed.

```sh
dsh plugin --profile web add dsh-context-redline@0.9.3
```
