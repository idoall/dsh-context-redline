# Context Redline v0.7.0 — handoff skill

<h3 id="cn-v0.7.0">新增：context-redline-handoff 技能</h3>

- 插件版本：`0.7.0`。支持 DSH `>=0.2.2-rc.5 <0.3.0-0`，针对 `0.2.2-rc.5` 构建与回归验证；要求 Node.js `>=24.9.0`。旧版 DSH 可继续使用插件 `0.6.1`。
- 插件注册一个运行时技能 `context-redline-handoff`：读取当前对话，输出四段可直接粘贴的内容——首条任务、目标、验收标准、执行纪律。
- 技能会区分“当前里程碑”和“整个目标”，并检查每条验收是否可执行/可观察；不确定的路径或命令会标“未验证”，不会编造。
- 执行纪律默认包含：出错修正并继续、每个里程碑停下等用户验收、每轮先读计划文件、不自行扩范围、证据必须真实。
- 技能只给文本，不建会话、不写文件、不改目标；把它给出的四段粘贴到「新建带规则的对话」即可。
- 技能通过 `ctx.inject(['skills'])` 注册：没有 skills 服务的老运行时只是不出现该技能，不影响面板；注册失败也不会拖垮插件。
- 保留 0.5.0/0.6.x 的趋势与锚定会话能力；同步中英文 README、CHANGELOG、支持范围与 npm 包内容。
- 自动化回归、构建和包检查不等于生产界面 / 真实会话人工验收，本次未执行生产重启或安装。

```sh
dsh plugin --profile web add dsh-context-redline@0.7.0
```

<h3 id="en-v0.7.0">New: context-redline-handoff skill</h3>

- Plugin version: `0.7.0`. Supports DSH `>=0.2.2-rc.5 <0.3.0-0`, built and regression-tested against `0.2.2-rc.5`; requires Node.js `>=24.9.0`. Older DSH users can stay on plugin `0.6.1`.
- The plugin registers a runtime skill, `context-redline-handoff`: it reads the current conversation and outputs four ready-to-paste blocks — first task, goal, acceptance criteria and execution discipline.
- The skill separates the current milestone from the whole goal and checks that every acceptance item is executable or observable; unknown paths or commands are marked unverified rather than invented.
- The default discipline covers fixing errors and continuing, stopping at each milestone for explicit user acceptance, reading the plan file every turn, not expanding scope, and requiring real evidence.
- The skill only produces text: it does not create sessions, write files or change the goal. Paste its four blocks into **New conversation with rules**.
- Registered through `ctx.inject(['skills'])`: an older runtime without a skills registry simply lacks the skill, and a failed registration never takes the panel down.
- Retains the 0.5.0/0.6.x trend and anchored-conversation capabilities; synchronizes both READMEs, the changelog, the support range and npm package contents.
- Automated regression, build and package checks are not production visual or real-session manual acceptance. No production restart or installation was performed.

```sh
dsh plugin --profile web add dsh-context-redline@0.7.0
```
