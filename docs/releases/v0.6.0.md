# Context Redline v0.6.0 — trend DNA mode

<h3 id="cn-v0.6.0">新增：趋势 DNA 指纹模式</h3>

- 插件版本：`0.6.0`。支持 DSH `>=0.2.2-rc.5 <0.3.0-0`，针对 `0.2.2-rc.5` 构建与回归验证；要求 Node.js `>=24.9.0`。旧版 DSH 可继续使用插件 `0.5.0`。
- 趋势卡新增「DNA」开关：每根柱子改为该步上下文的逐条色带指纹——系统提示词、工具定义在前，随后是模型读取顺序的消息；颜色沿用分类色板。
- 浏览器的 DNA 开关与趋势开关联动：打开任一处，两张卡同时进入 DNA 模式；关闭同理。
- DNA 模式当前固定为**总计语义**：色带就是该步的组成，因此「增量」按钮在 DNA 开启时禁用；DNA + 增量组合与色带点击跳转到浏览器条目不在本版范围内。
- 趋势标题不再显示「按轮次（共 N 轮）/ 刻度」读数，与参考插件的标题结构同步；轮次/步骤与大小仍由按钮和坐标轴表达。
- 持久化状态版本保持 24（DNA 是纯客户端视图，不新增宿主字段）；README 总览截图随趋势标题与 DNA 开关更新。
- 同步中英文 README、CHANGELOG、支持范围与 npm 包内容。保留 0.5.0 的耗时曲线、锚定会话与两种锚点方式。
- 不包含未验收的体检功能、carrier-seed 实验或参考插件的固定块/团队入口。自动化回归、构建和包检查不等于生产界面 / 真实会话人工验收，本次未执行生产重启或安装。

```sh
dsh plugin --profile web add dsh-context-redline@0.6.0
```

<h3 id="en-v0.6.0">New: trend DNA mode</h3>

- Plugin version: `0.6.0`. Supports DSH `>=0.2.2-rc.5 <0.3.0-0`, built and regression-tested against `0.2.2-rc.5`; requires Node.js `>=24.9.0`. Older DSH users can stay on plugin `0.5.0`.
- The trend card gains a **DNA** toggle: each bar becomes a per-item gradient fingerprint of that step’s context — system prompt and tool schemas first, then the messages in the model’s read order, colored by the category palette.
- The browser’s DNA switch and the trend switch move together: turning either one on enters DNA mode on both cards, and off does the same in reverse.
- DNA currently forces **total semantics**: the bands are the step’s composition, so the Delta button is disabled while DNA is on. DNA + Delta and band click-through to a browser row are out of scope for this release.
- The trend title drops the “by turn (N turns) / scale” readout, matching the reference title structure; turn/step size remains expressed by the buttons and the axis.
- The persisted state stays at version 24 (DNA is a pure client view with no new host field); the README overview screenshot follows the title and DNA switch changes.
- Synchronizes both READMEs, the changelog, the support range and npm package contents. Retains the 0.5.0 duration overlay, the anchored conversation and both anchor modes.
- Excludes unaccepted diagnostics, carrier-seed experiments and the reference plugin’s fixed blocks/team entry. Automated regression, build and package checks are not production visual or real-session manual acceptance. No production restart or installation was performed.

```sh
dsh plugin --profile web add dsh-context-redline@0.6.0
```
