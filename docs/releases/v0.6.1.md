# Context Redline v0.6.1 — DNA switch state fix

<h3 id="cn-v0.6.1">修复：从浏览器打开 DNA 时趋势模式未复位</h3>

- 插件版本：`0.6.1`。支持 DSH `>=0.2.2-rc.5 <0.3.0-0`，针对 `0.2.2-rc.5` 构建与回归验证；要求 Node.js `>=24.9.0`。旧版 DSH 可继续使用插件 `0.6.0`。
- 现象：先在趋势里切到「增量」，再从上下文浏览器打开 DNA。趋势图已按 DNA 的总计语义绘制，但「增量」按钮仍然显示为选中（只是被禁用），状态自相矛盾。
- 修复：两个 DNA 开关共用一个处理函数；开启 DNA 时同时把趋势复位到「总计」。关闭 DNA 时保留当前模式，不额外改写用户选择。
- DNA 仍是总计语义；DNA + 增量、色带点击跳转仍不在本版范围。
- 只改客户端状态同步，不新增宿主字段、不调用模型、不改会话；持久化状态版本保持 24。
- 自动化回归、构建和包检查不等于生产界面 / 真实会话人工验收，本次未执行生产重启或安装。

```sh
dsh plugin --profile web add dsh-context-redline@0.6.1
```

<h3 id="en-v0.6.1">Fix: trend mode not reset when DNA opens from the browser</h3>

- Plugin version: `0.6.1`. Supports DSH `>=0.2.2-rc.5 <0.3.0-0`, built and regression-tested against `0.2.2-rc.5`; requires Node.js `>=24.9.0`. Older DSH users can stay on plugin `0.6.0`.
- Symptom: switch the trend to Delta, then open DNA from the Context browser. The chart already plots DNA's total semantics, but the Delta segment still looks selected (only disabled), leaving a contradictory state.
- Fix: both DNA switches now share one handler that parks the trend at Total when DNA turns on. Turning DNA off preserves the current mode instead of rewriting the user's choice.
- DNA remains total-only; DNA + Delta and band click-through are still out of scope.
- Client-side state sync only: no host field, model call or session write; the persisted state stays at version 24.
- Automated regression, build and package checks are not production visual or real-session manual acceptance. No production restart or installation was performed.

```sh
dsh plugin --profile web add dsh-context-redline@0.6.1
```
