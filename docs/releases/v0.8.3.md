# Context Redline v0.8.3 — DSH 0.2.3-alpha.2 compatibility

<h3 id="cn-v0.8.3">跟随 DSH 0.2.3-alpha.2：系统提示词按“全部幸存消息求和”计价</h3>

- 插件版本：`0.8.3`。支持 DSH `>=0.2.3-alpha.2 <0.3.0-0`，针对 `0.2.3-alpha.2` 构建与回归验证；要求 Node.js `^24.22.3 || >=26.13.1`。旧版 DSH 可继续使用插件 `0.8.2`。
- 按官方 upgrade guide（`0.2.2-rc.5` → `0.2.3-alpha.2`）逐条核对：
  - `ctx.sessionQuery.inspectSession` 已移除：本插件只读 `readSession` 与可选的 `observeSession`，不调用它；
  - 系统提示词改为“章节更新”：后续 `system/message` 只携带变化的章节，DSH 把所有幸存的系统消息拼接进请求，并按求和计价（宿主自己的 `contextBreakdown` 就是求和）；
  - Node.js 门槛提升到 `24.22.3`（24.x）或 `26.13.1`（26.x）。
- 修复：系统提示词卡片此前按“最后一条非空系统消息”计价与展示，遇到章节更新会把一份上万 token 的提示词显示成几百 token 的增量片段。现在与宿主一致：
  - `系统提示词` 数字 = 所有幸存系统消息之和；
  - 文本区把头部提示词与每条章节更新按顺序拼接（每条一次按需读取，失败可重试）；
  - DNA 条的系统带取同样的总和；压缩（compaction）遮蔽掉的系统消息同步移出，不再重复计价。
- 持久化状态版本 24 → 25：按旧规则记下的系统提示词数值是错的，缓存行必须重新 fold；没有新增宿主字段、模型调用或会话写入，也不读写来源会话、不改预设系统提示词或工具定义。
- 自动化回归、构建与包检查不等于生产界面或真实会话人工验收；本次未执行生产重启或安装。

```sh
dsh plugin --profile web add dsh-context-redline@0.8.3
```

<h3 id="en-v0.8.3">Follow DSH 0.2.3-alpha.2: price the system prompt as the sum of its surviving messages</h3>

- Plugin version: `0.8.3`. Supports DSH `>=0.2.3-alpha.2 <0.3.0-0`, built and regression-tested against `0.2.3-alpha.2`; requires Node.js `^24.22.3 || >=26.13.1`. Older DSH users can stay on plugin `0.8.2`.
- Checked against the official upgrade guides (`0.2.2-rc.5` → `0.2.3-alpha.2`):
  - `ctx.sessionQuery.inspectSession` is removed; this plugin reads cold logs through `readSession` and the optional `observeSession` and never calls it;
  - the system prompt became SECTION UPDATES: a later `system/message` carries only the changed sections, the harness concatenates every surviving system message into the request, and prices them by summing their nodes (the host's own `contextBreakdown` sums them);
  - the Node.js floor moved to `24.22.3` (24.x) or `26.13.1` (26.x).
- Fixed: the system-prompt card priced and displayed "the last nonempty system message", so a section update made a ten-thousand-token prompt look like a few-hundred-token fragment. It now matches the host:
  - the `System Prompt` figure is the SUM of every surviving system message;
  - the text section joins the head prompt and its section updates in order (one on-demand read per message, with retry);
  - the DNA strip's system band carries the same sum, and system messages shadowed by compaction leave the list instead of being counted twice.
- Persisted state version 24 → 25: rows folded under the old rule carry a wrong system-prompt figure, so cached rows refold from the log; no new host field, model call, or session write, and no source-session or preset-layer change.
- Automated regression, build and package checks are not production visual or real-session manual acceptance. No production restart or installation was performed.

```sh
dsh plugin --profile web add dsh-context-redline@0.8.3
```
