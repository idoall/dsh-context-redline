# Context Redline v0.1.3 — DSH 0.2.2-rc.5 compatibility

<h3 id="cn-v0.1.3">兼容性更新</h3>

- 插件版本：`0.1.3`。支持 DSH `>=0.2.2-rc.5 <0.3.0-0`，针对 `0.2.2-rc.5` 构建与回归验证；要求 Node.js `>=24.9.0`。旧 DSH 用户可继续使用插件 `0.1.2`；本版本不支持 DSH `0.3.0` 预发布版。
- DSH `0.2.2-rc.5` 现为 npm `latest` 标签。该版本仅调整 DeepSeek 模型的服务端搜索策略，未修改本插件使用的 Session Query、Agent、预设、工作区、会话投影与 Client 插槽接口。
- 同步开发依赖与对等依赖下限到 `0.2.2-rc.5`（Zod 4.6.6、`dsh-error` 对等依赖继续保留），并复核 0.2.2 系列此前的批量追加、工具错误类型与投影异步注册契约仍然兼容。
- 保留 0.1.1 / 0.1.2 的行为修复：读取会话当前模型与预设、等待异步投影注册并使用保留句柄、保留新版工具结果历史正文与错误状态。
- 同步中英文 README、CHANGELOG、支持范围与 npm 包内容；GitHub Release 仍等待 npm 发布成功后创建。
- 不包含未验收的体检功能、carrier-seed 实验或其他本地未发布改动；不重写来源会话。自动化回归、构建和包检查不等于生产界面 / 真实会话人工验收，本次未执行生产重启或安装。

```sh
dsh plugin --profile web add dsh-context-redline@0.1.3
```

如安装结果提示需要重启，由用户本人重启 `dsh web`。

<h3 id="en-v0.1.3">Compatibility update</h3>

- Plugin version: `0.1.3`. Supports DSH `>=0.2.2-rc.5 <0.3.0-0`, built and regression-tested against `0.2.2-rc.5`; requires Node.js `>=24.9.0`. Older DSH users can stay on plugin `0.1.2`; DSH `0.3.0` prereleases are excluded.
- DSH `0.2.2-rc.5` is now the npm `latest` tag. That release only adjusts DeepSeek models' server-side search strategy and does not change the Session Query, Agent, preset, workspace, session-projection or Client slot interfaces used here.
- Move development and peer dependency floors to `0.2.2-rc.5` (Zod 4.6.6 and the `dsh-error` peer stay), and recheck the earlier 0.2.2-series contracts for batched append, tool error types and asynchronous projection registration.
- Retain the 0.1.1 / 0.1.2 fixes: read the Session's current model and preset, await asynchronous projection registration and use the retained handle, and preserve current tool-result history content and failure status.
- Synchronize both READMEs, the changelog, the support range and npm package contents. The GitHub Release still waits for successful npm publication.
- Excludes unaccepted diagnostics, carrier-seed experiments and other unpublished local work; source sessions remain append-only. Automated regression, build and package checks are not production visual or real-session manual acceptance. No production restart or installation was performed.

```sh
dsh plugin --profile web add dsh-context-redline@0.1.3
```

If installation reports that a restart is required, restart `dsh web` yourself.
