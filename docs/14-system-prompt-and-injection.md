# 系统提示词与注入边界

## 三层必须区分

| 层 | 所有者 | 本插件能做什么 |
|---|---|---|
| 目标会话真实系统提示词 | DSH + agent preset | 选择并挂载 preset；不能用普通迁移文本替换 |
| 工具定义 | DSH + preset / tool registry | 不编辑、不迁移 schema |
| 来源会话中的历史材料 | Session surface | 可按来源身份迁移为普通用户消息中的带标签材料 |

迁移正文即使来源于 system / inject / skill，也必须明确说明它只是历史材料，不是目标会话的真实系统层。

## 系统提示词

- 目标 root Agent 使用确认时冻结的 `agentPreset`。
- 创建 / 恢复时通过公开 preset 服务挂载。
- 插件在投递前核对实际 composed preset。
- 历史 system material 可以作为普通迁移文本出现，但不能声明“已经修改目标系统提示词”。
- 来源日志中的 system/message 不会被改写。

## 工具定义

工具 schema 不是普通 surface 正文，也没有本插件可用的历史替换语义。要改变目标会话工具，只能选择另一套预设或由平台配置负责。

本插件不会：

- 把工具定义复制进普通文本后声称工具已启用；
- 根据来源会话工具列表限制目标 Agent；
- 修改历史 request/header；
- 在界面提供虚假的工具定义编辑按钮。

## 注入和技能材料

来源 surface 中可稳定识别的 inject / skill 文本可以迁移。序列化时必须保留原来源标签，并说明它只是迁移材料。

本地编辑仅改变迁移副本。来源会话下一轮仍由原插件和原预设重新注入自己的内容。

## 模型与推理等级

- 模型默认沿用来源会话，但用户可在确认框改选。
- 推理等级默认使用目标模型公布的默认值。
- 选择只写入新 root Agent 的 `agentOptions`，不调用来源会话 `selectModel`，不修改全局默认。
- 宿主在授权前解析模型实际默认推理等级并冻结；创建后核对新 Agent 的实际 provider / model / reasoning effort。
- 自动回程若需要冷恢复来源会话，使用单独冻结的来源恢复配置，不能使用新会话配置。

## 验证要求

- 来源与目标配置分开冻结并校验指纹；
- 选择另一模型不会改变来源 Agent options；
- “模型默认值”会冻结为适配器公布的实际默认档位；
- 模型或推理档不可用时，在创建前拒绝；
- preset 不一致或无法核实时零投递；
- 迁移文本永远不冒充目标 system/tool 层。
